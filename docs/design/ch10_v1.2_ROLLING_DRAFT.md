## 10.3.3 `bot_state` テーブル（v1.2 改訂）

v1.1 のスキーマに 2 列追加。既存列は変更なし。

```sql
CREATE TABLE bot_state (
  id INTEGER PRIMARY KEY CHECK (id = 1),
  state TEXT NOT NULL CHECK (state IN (
    'INITIALIZING', 'IDLE', 'TRADING', 'MONITORING_POSITION',
    'NIGHTLY_REVIEW', 'EMERGENCY_STOP', 'ERROR', 'SHUTDOWN', 'BACKTEST'
  )),
  mode TEXT NOT NULL CHECK (mode IN ('BACKTEST', 'PAPER', 'SIMMER', 'LIVE')),
  balance REAL NOT NULL,
  daily_pnl REAL NOT NULL DEFAULT 0,
  daily_loss_limit REAL NOT NULL,
  ws_polymarket_connected INTEGER NOT NULL DEFAULT 0,
  ws_binance_connected INTEGER NOT NULL DEFAULT 0,
  current_strategy_version INTEGER NOT NULL,
  last_updated TEXT NOT NULL,
  started_at TEXT NOT NULL,
  -- v1.2 追加
  principal REAL NOT NULL DEFAULT 0,
  locked_principal REAL NOT NULL DEFAULT 0
);
```

### 派生量（DB 列ではない）

- `withdrawable_principal = principal − locked_principal`
- `cumulative_pnl = balance − principal`

### 既存 DB マイグレーション

1. `ALTER TABLE` で 2 列 DEFAULT 0 追加
2. `principal := balance`（既存残高を初期入金とみなす）
3. `locked_principal := Σ(open positions の元本拘束額)`
4. `principal_transactions` に 1 行: `DEPOSIT`, `note='migration:v1.2_initial'`

実行: `yoruu db migrate`（ch22 追補で定義、本章は参照のみ）

## 10.3.14 `principal_transactions` テーブル（v1.2 新規）

  id INTEGER PRIMARY KEY AUTOINCREMENT,

  balance_before REAL NOT NULL,
  balance_after REAL NOT NULL,

## 10.6.x 元本 API（v1.2 新規）

### `POST /api/v1/principal/deposit`

- Body: `{ "amount": 500.00, "note": "..." }`
- 検証: `amount > 0`, `amount <= max_deposit_per_tx`（ch22、デフォルト 100000.00 USD）
- 副作用: `principal += amount`, `balance += amount`；SSE `principal_changed`；`audit_log`

### `POST /api/v1/principal/withdraw`

- Body: `{ "amount": 200.00, "note": "...", "confirm": true }`
- 検証: `amount <= withdrawable_principal`（超過 `E_PRINCIPAL_001`）、**`confirm: true` 必須**
- 副作用: deposit と対称

### `GET /api/v1/principal`

サマリ: `principal`, `locked_principal`, `withdrawable_principal`, `balance`, `cumulative_pnl`, 件数・日時。

### `GET /api/v1/principal/transactions`

クエリ: `from`, `to`, `kind`, `limit`（上限 500）, `offset`。
