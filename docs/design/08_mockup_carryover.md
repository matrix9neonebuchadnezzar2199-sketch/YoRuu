## 3. 共通レイアウト

- **サイドバー**: 左 240px 固定、全画面共通
- **モード表示**: サイドバー上部 + ヘッダー固定バー（paper=灰 / simmer=青 / live=赤）
- **ヘルスバナー**: 画面上部固定、WS切断・APIエラー・ディスク残量・夜間レビュー未消化を SSE で push
- **コマンドパレット**: `Cmd/Ctrl+K`、緊急停止・モード切替・設定を即座に呼び出し
- **アイコン**: 絵文字は使用しない、インライン SVG + `t('nav.*')` テキスト

---

## 4. 緊急停止の二重配置（重要）

緊急停止ボタンは**2箇所に常時配置**する。誤タップ防止と即時アクセスの両立。

| 配置場所 | 仕様 | 用途 |
|----------|------|------|
| サイドバー最下部 | 通常時は控えめ（`--danger-fg` 文字色のみ）、ホバー時に背景強調 | どの画面からも1クリック |
| ダッシュボード右下 | 単色 `--danger-fg`、他ボタン比 70%、周囲 40px パディング | メイン画面・誤タップ防止 |

**両方とも確認ダイアログなし**で即時発火（→ 第3章、第6章 6.7）。

---

## 5. 夜間レビュー Apply 画面の仕様

- 差分表示: `旧値 → 新値`、変化率 % 併記
- 範囲外は赤ハイライト
- 変化率 ±10% 超は黄色警告
- Apply ボタンは差分確認後にのみ活性化

## 10. SSE イベント（第7章 §7.5 へバックポート予定）

| イベント名 | 用途 |
|-----------|------|
| `markov_update` | Markov 確率の更新 |
| `health_degraded` | ヘルス劣化 |
| `position_opened` | 建玉（既存 `trade_opened` と統合検討） |
| `position_closed` | 決済（既存 `trade_closed` と統合検討） |
| `nightly_report_ready` | 夜間レポート完了（既存 `review_available` と統合検討） |
| `mode_changed` | モード切替（既存 `mode_change` と統合検討） |
| `emergency_stop_triggered` | 緊急停止（既存 `critical` と統合検討） |

第8章設計時に既存イベント名との統一を確定する。
