# 第8章 UI モック — 補助レビュー反映予約

> 第1〜7章の補助レビュー対応（2026-05-27）に伴い、第8章 HTML モック作成時に必ず反映する事項を記録する。本章本文は未作成。

## レイアウト・安全 UX

| 要素 | 仕様 |
|---|---|
| 緊急停止ボタン | ダッシュボード右下隅。単色 `--critical` (#8e1f1f)。他ボタン比 70% サイズ。周囲 40px パディング（誤タップ防止）。確認ダイアログなし |
| モード表示バー | 画面上部固定。paper=灰 / simmer=青 / live=赤。常時表示 |
| 夜間レビュー Apply | 差分表示（旧値 → 新値、変化率%）。範囲外は赤ハイライト。二重承認フロー (→ 第6章 6.5) |
| backtest | 別画面または別タブ。リアルタイム取引 UI と物理分離 (→ 第3章 3.3備考、第13章) |

## 設計との対応

- `PERSISTENCE_THRESHOLD` の Apply プレビューは 0.50〜0.90 範囲外を赤表示 (→ 第7章 7.2.1)
- 状態機械の遷移は UI から直接行わず API → StateMachine 経由 (→ 第6章)
