## 設計判断（推奨採用・自動確定）

| 論点 | 確定 |
|------|------|
| `initial_balance` | **`initial_principal` リネーム**、旧キー**無期限受付**（DeprecationWarning） |
| `max_deposit_per_tx` / `max_withdraw_per_tx` | **100000.0 USD**（対称） |
| 為替 | 独立セクション **`display.*`**（`ui` とは分離） |
| FX provider | **exchangerate.host**、更新 **15 分** |
| FX 失敗 | 最終成功値 `stale=true`、完全失敗は fallback → USD 強制 |
| マイグレーション | **`yoruu db migrate`**（`--dry-run` 対応） |
| `display.*` | 全モード**任意** |

## 22.2 完全スキーマ（v1.0.5 改訂・抜粋）

```yaml
mode: PAPER
initial_principal: 1000.0    # 旧 initial_balance も受付（§22.9）
currency: USD

principal:
  max_deposit_per_tx: 100000.0
  max_withdraw_per_tx: 100000.0
  require_confirm_on_withdraw: true

display:
  currency_default: USD
  fx:
    enabled: true
    provider: exchangerate.host
    update_interval_min: 15
    timeout_sec: 5
    fallback_rate_usd_jpy: 156.50
    cache_max_age_min: 60

# websocket / risk / paths / ui / paper … v1.0.4 と同一
```

### 22.2.2 元本設定 SSOT（v1.0.5 新規）

| キー | デフォルト | 用途 |
|------|----------|------|
| `principal.max_deposit_per_tx` | 100000.0 | DEPOSIT 上限 → `E_PRINCIPAL_003` |
| `principal.max_withdraw_per_tx` | 100000.0 | WITHDRAW 上限 → `E_PRINCIPAL_006` |
| `principal.require_confirm_on_withdraw` | true | `confirm: true` 必須 → `E_PRINCIPAL_004` |

`initial_principal` = 起動時初期入金（マイグレーションで `principal_transactions` 1 行化）。`PrincipalService` は本章参照のみ（ch13 §13.2.6）。

### 22.2.3 表示換算（FX）SSOT（v1.0.5 新規、F-2）

| キー | デフォルト |
|------|----------|
| `display.currency_default` | USD |
| `display.fx.enabled` | true |
| `display.fx.provider` | exchangerate.host |
| `display.fx.update_interval_min` | 15 |
| `display.fx.fallback_rate_usd_jpy` | 156.50 |
| `display.fx.cache_max_age_min` | 60 |

取得失敗: キャッシュ → stale 返却 → fallback → HUD は USD 強制。ch10 §10.6.13、`localStorage` で通貨上書き可。

## 22.3 検証ルール（追加分）

- `initial_principal` > 0（旧 `initial_balance` 同条件）
- `principal.max_*` > 0
- `display.currency_default` ∈ {USD, JPY}
- `display.fx.*` 範囲制約（interval 1〜1440 等）

`yoruu config validate` 追従（M4.4）。

## 22.10 マイグレーション CLI（v1.0.5 新規）

```
yoruu db migrate [--dry-run] [--from-version] [--to-version]
```

**v1.x → v1.2 手順**:

1. DB バックアップ
2. `ALTER TABLE bot_state ADD principal`
3. `CREATE TABLE principal_transactions`
4. `principal := balance + Σ(open size)`
5. migration DEPOSIT 1 行
6. INV-D-06 v2 / 07 / 09 検証（失敗時ロールバック）
7. yaml の `initial_balance` は警告のみ（自動書換えしない）
