## §13.2.5 D11 v2 サマリ

| イベント | balance | principal |
|---------|---------|-----------|
| open 成功 | `-= size_usd`（v1 維持） | — |
| close 成功 | `+= size_usd + pnl`（v1 維持） | — |
| DEPOSIT | `+= amount` | `+= amount` |
| WITHDRAW | `-= amount`（`<= balance`） | `-= amount` |

`locked_principal` は positions 集計の派生量（ch10 v1.2）。

### INV-D-06 v2

```
balance + locked_principal == principal + Σ(closed_trades.pnl)
```

許容誤差 **0.02 USD**（v1 同様）。
