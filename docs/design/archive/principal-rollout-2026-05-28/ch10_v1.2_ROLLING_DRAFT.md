## 10.3.3 `bot_state`（v1.2 追補）

v1.1 スキーマに **1 列**追加:

```sql
  principal REAL NOT NULL DEFAULT 0   -- 累積入金 − 累積出金
```

`locked_principal` は **DB 列として持たない**（`Σ(positions.size_usd WHERE status='OPEN')` で派生）。

### 派生量（UI / API）

| 量 | 定義 |
|----|------|
| `locked_principal` | `Σ(open positions.size_usd)` |
| `withdrawable_principal` | `balance`（H-1: 自由資金） |
| `total_assets` | `balance + locked_principal`（HUD ヒーロー「残高」） |
| `cumulative_pnl` | `total_assets − principal` |

### マイグレーション（v1.2）

1. `ALTER TABLE bot_state ADD COLUMN principal REAL NOT NULL DEFAULT 0`
2. `principal := balance + Σ(positions.size_usd WHERE status='OPEN')`
3. `principal_transactions` に `migration:v1.2_initial` 行
4. 実行: `yoruu db migrate`（ch22 §22.x）
