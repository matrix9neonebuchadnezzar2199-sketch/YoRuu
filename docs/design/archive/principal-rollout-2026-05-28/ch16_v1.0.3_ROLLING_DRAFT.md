### 16.3.1 INV-D-06（残高保存則 v2）— v1.0.3 改訂

**改訂内容**: v1 の `initial_balance` を `principal` に置換。元本概念導入（A-2 + B-2、PHASE 4 M4.3）に伴う拡張。

**適用**: PAPER / SIMMER（内部台帳）。BACKTEST は別集計、LIVE は API 残高が主だが内部台帳も整合を推奨。

**式（一次形式）**:

```
total_assets ≈ principal + Σ(closed_trades.pnl)
```

**式（展開形式、実装検査式）**:

```
balance + Σ(open_positions.size_usd) ≈ principal + Σ(closed_trades.pnl)
```

| 項 | 意味 |
|----|------|
| `balance` | `bot_state.balance`（自由資金、H-1） |
| `Σ(open.size_usd)` | 未決済建玉合計（= 派生 `locked_principal`） |
| `total_assets` | `balance + locked_principal`（HUD ヒーロー） |
| `principal` | `bot_state.principal`（ch10 v1.2 §10.3.3） |
| `Σ(closed.pnl)` | 決済済み `trades.pnl` 累計 |

**v1 との後方互換**: `principal_transactions` が空（または起動時 initial DEPOSIT 1 行のみ）では `principal == initial_balance` となり v1 と等価。v1.2 マイグレーションで `principal := balance + Σ(open_size)` により直後も等価（ch10 §10.3.3）。

**更新規則（SSOT: ch13 §13.2.5 D11 v2）**:

- open: `balance -= size_usd`、`principal` 不変
- close: `balance += size_usd + pnl`、`principal` 不変
- DEPOSIT: `balance`/`principal` 同額加算
- WITHDRAW: 同額減算

**検査**: `check_post_open` / `check_post_close`（既存）+ `check_post_principal_change`（新規、M4.4）。severity: **ERROR**。

**cross-ref**: ch13 §13.2.5、ch10 §10.3.3/§10.3.14、`paper_executor.py`、`principal/service.py`、`invariants.py`。

### 16.3.2 INV-D-07（principal 保存則）— v1.0.3 新規

**適用**: PAPER / SIMMER / LIVE。BACKTEST は別集計。

**式**:

```
bot_state.principal == Σ(DEPOSIT.amount) − Σ(WITHDRAW.amount)
```

許容誤差: **0.01 USD**。

**検査タイミング**: DEPOSIT/WITHDRAW 直後、5 分境界、起動時。

**severity**: **ERROR**。

**cross-ref**: ch10 §10.3.14、ch13 §13.2.6。

### 16.3.3 INV-D-08（withdraw 制約）— v1.0.3 新規

**適用**: PAPER / SIMMER / LIVE。

**式**:

```
∀ tx ∈ principal_transactions WHERE kind='WITHDRAW':
    tx.amount <= tx.balance_before
```

H-1 では `withdrawable_principal == balance` と同義。

**検査タイミング**: WITHDRAW API バリデーション時、起動時の履歴検証。

**severity**: **ERROR**（事前 `E_PRINCIPAL_001`、事後は不変条件）。

**cross-ref**: ch13 §13.2.6、ch18 `E_PRINCIPAL_001`。

### 16.3.4 INV-D-09（principal/balance 非負）— v1.0.3 新規

**適用**: PAPER / SIMMER / LIVE。

**式**:

```
bot_state.principal >= 0 AND bot_state.balance >= 0
```

**検査タイミング**: 5 分境界、open/close/deposit/withdraw 直後。

**severity**: **ERROR**。

**cross-ref**: ch13 §13.2.5/§13.2.6、`invariants.py`。
